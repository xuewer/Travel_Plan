# 🌍 基于 LangGraph 的自适应多智能体精细化旅游路线编排系统

本项目是一款基于 **LangGraph** 和 **Pydantic V2** 构建的工业级、自适应多智能体工作流框架。它通过多智能体有向无环图（DAG）拓扑结构，成功将大模型（LLM）传统生成中不可控、易漂移的文本响应，高效驯服为 100% 类型安全、生产可解析的精细化嵌套结构化旅行方案。

---

## 🚀 核心架构亮点

* **显式状态契约（Explicit State Contract）**：利用 LangGraph 的全局统一状态图（`PlannerState`），完美解决多轮复杂对话与跨节点交互中的数据丢失与状态错乱问题。
* **Pydantic V2 强约束提取**：深度结合大模型的 `.with_structured_output()` 特性，强行约束 LLM 必须严格对齐深度嵌套的 JSON Schema（`FullTravelPlan` -> `DailyItinerary` -> `ScenicSpot`），从根本上杜绝幻觉（Hallucination）与字段缺失。
* **增量状态状态突变（Incremental State Mutation）**：节点设计摒弃了传统的全量状态解包复制（`**state`），采用更优雅的字典增量合并机制（`-> dict`），彻底消除了静态类型检查工具（如 PyCharm）的编译期警告，并优化了运行期内存开销。
* **关注点分离（SoC 原则）**：严格按照高内聚低耦合的软件工程规范，将系统解耦为数据模型层（`schemas`）、智能体推理层（`agents`）、人类协同节点层（`nodes`）以及图编排入口（`app`），具备极高的生产可维护性。
